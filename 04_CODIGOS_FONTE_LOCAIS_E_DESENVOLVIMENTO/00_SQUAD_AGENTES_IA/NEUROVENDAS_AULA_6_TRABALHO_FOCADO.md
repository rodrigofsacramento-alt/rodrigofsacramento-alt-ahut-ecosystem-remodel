2. **LIMPIÁ ANTES / LIMPE ANTES:** el teléfono, las notificaciones, el ruido. Antes de entrar, apagá el mundo.

5. **EL ESTADO SE CONTAGIA / O ESTADO SE CONTAGIA:** si estás disperso, el cliente se dispersa. Si estás profundo, el cliente puede decidir.
